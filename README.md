# extractable-facts — split into three repos

This repo has been **superseded**. Its three skills now live in their own repositories, so you can install only the one you need:

| Skill | Repo |
|---|---|
| **query-match-audit** — does your page match the queries you want to win, and is it worth retrieving? | https://github.com/mmakosiewicz/query-match-audit |
| **ai-extractability-audit** — can AI search engines chunk, understand and cite its facts? | https://github.com/mmakosiewicz/ai-extractability-audit |
| **blog-style-editing** — editorial craft rules for the prose underneath both | https://github.com/mmakosiewicz/blog-style-editing |

They stack: be *relevant* enough to retrieve, *extractable* enough to quote, *well written* enough to deserve it.

This repository is archived and no longer updated.
